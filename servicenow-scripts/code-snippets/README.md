# Code Snippets

Copy-paste reference snippets for common ServiceNow development tasks.

## Sub-categories

| Folder | Description |
|---|---|
| `glide-record/` | GlideRecord CRUD and query patterns |
| `rest-api/` | Inbound and outbound REST examples |
| `json-xml/` | JSON and XML parsing/building |
| `date-time/` | Date, time, and SLA calculations |
| `miscellaneous/` | Attachments, ACLs, Workflow, Properties |

## Usage

These are not deployable scripts on their own — they are reference snippets to be copied into your Business Rules, Script Includes, or other ServiceNow script fields. Each snippet is annotated with the context where it applies.
